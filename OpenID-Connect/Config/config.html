User Access & Permissions

When enabled, users will be automatically created. If a jellyfin user with the same name already exists and is not on the auto-linking list, this will create a user with a unique suffix.
If enabled, user profile pictures and permissions are updated on every login. If disabled, permissions and profile pictures are only set on creation.
One role per line. If the user has any of these roles in their OIDC response, they are authenticated. Leave blank to disable role checking. Validated against Role Claim.
One role per line. Users with any of these roles receive admin privileges. Leave blank to not auto-grant admin. Users with any of these roles also automatically gain access and do not need a role from Allowed Roles.
Select existing local users that should be automatically linked the first time they log in via this provider. Any user with the same username in the IdP as a user in this list will be automatically linked to that user. If users are able to customize their own names in the IdP, ensure that you trust them, users with the same IdP name as the jellyfin administrator account name can take control over the jellyfin account. Once successfully linked, the user is automatically removed from this list.

Live TV

Does not automatically grant viewing permission.
Use roles to grant Live TV privileges. If Grant Live TV Access or Grant Live TV Management are enabled, RBAC does not override those, and permissions will be granted regardless of roles.
One role per line. Users with any of these roles can view Live TV.
One role per line. Users with any of these roles can manage Live TV. Access to Live TV management does not automatically grant access to Live TV viewing, add roles to both to enable both viewing and management.
